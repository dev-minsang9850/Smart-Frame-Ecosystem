[ 윈도우용 액자 매니저 앱 만드는 방법 ]
현재 개발 환경이 Mac(맥)이므로 윈도우용 프로그램(.exe)은 윈도우 컴퓨터에서 직접 클릭 한 번으로 생성하셔야 합니다.

1. '액자_매니저_윈도우_빌드_소스' 폴더를 통째로 윈도우 컴퓨터(또는 윈도우 노트북)로 복사합니다.
2. 폴더 안에 있는 'Windows_빌드_실행.bat' (또는 'build_windows_app.bat') 파일을 더블 클릭하여 실행합니다.
3. 검은색 창이 뜨면서 자동으로 필요한 파일들을 설치하고 앱을 만듭니다. (약 1~2분 소요)
4. 완료되면 'dist' 라는 새 폴더가 생기며, 그 안에 완벽한 '액자 매니저 앱.exe' 파일이 만들어집니다!
5. 이제 그 .exe 파일 하나만 바탕화면이나 SD카드에 복사해서 사용하시면 됩니다.
