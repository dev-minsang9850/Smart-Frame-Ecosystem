# 📸 디지털 전자 액자 (Digital Smart Frame) 프로젝트

본 문서는 **'디지털 전자 액자'**를 누구나 쉽고 완벽하게 사용할 수 있도록 만들기 위해 진행했던 **다양한 기술적 시도와 시행착오(Troubleshooting)**, 그리고 그 과정을 거쳐 도달한 **현재의 완성된 형태**를 기록한 개발 일지입니다.

---

## 1. 프로젝트 개요
- **프로젝트명**: 디지털 전자 액자 (Digital Smart Frame)
- **목표**: 개발 지식이 없는 일반 사용자도 스마트폰이나 PC의 사진을 선 연결의 불편함 없이 쉽게 모으고, 아두이노(ESP32) 기반 전자 액자에 최적화된 상태로 띄울 수 있는 완벽한 올인원 시스템 구축.
- **주요 활용 하드웨어**: ESP32-2432S028R (CYD 보드, SD카드 방식), ESP32-C3 (1.44인치, 내장 메모리 방식)

---

## 2. 목표 달성을 위한 여러 가지 시도와 시행착오

프로젝트를 진행하며 우리는 '사진 전송과 출력'이라는 단순해 보이는 목표를 달성하기 위해 다양한 플랫폼(웹, 데스크톱, 임베디드)을 넘나들며 여러 시도를 진행했습니다.

### 시도 1. 모바일 사진 수집을 위한 웹 서버 구축 (PixShare)
가장 먼저 사용자의 스마트폰에 있는 사진을 PC로 쉽게 모으기 위해 **Node.js(Express) 기반의 로컬 사진 공유 웹앱**을 개발했습니다. QR 코드를 통해 쉽게 접속하고 다크 테마/글래스모피즘 UI를 적용했습니다.
- 🚨 **트러블슈팅**: 
  - Express 5.x의 와일드카드 라우팅(`*`)이 내부 모듈과 충돌하여 서버가 크래시되는 문제를 `app.get('/')`로 수정하여 해결했습니다.
  - 드래그 앤 드롭 영역(`.drop-zone`) 내에서 파일 입력창 태그가 중첩되어 브라우저가 클릭을 차단(이벤트 버블링)하는 현상을 겪었고, 명시적인 버튼을 밖으로 빼내어 해결했습니다.

### 시도 2. 액자 최적화를 위한 데스크톱 매니저 개발 (PyQt5)
모인 사진들을 아두이노가 읽을 수 있도록 변환해주는 **PC용 데스크톱 매니저(Smart Frame Manager)**를 개발했습니다.
- 🚨 **트러블슈팅**: 
  - 아이폰으로 찍은 세로 사진이 액자에서는 가로로 누워서 출력되거나, HEIC 포맷을 아두이노가 거부하는 치명적인 문제가 발생했습니다. 매니저 앱에서 EXIF 꼬리표를 읽어 사진을 강제로 똑바로 세운 뒤, 메타데이터를 삭제하고 순정 RGB JPEG로 변환하는 로직을 도입해 극복했습니다.
  - Mac OS에서 앱 구동 시 버튼이 까맣게 타고 흰색 네모 박스가 깨지는 CSS 렌더링 버그를 `QApplication.setStyle('Fusion')`을 강제 적용하여 해결했습니다.

### 시도 3. 다양한 하드웨어 및 전송 방식의 테스트
- **SD 카드 vs USB 시리얼**: 처음에는 USB 선을 통한 시리얼 통신으로 사진을 전송하려 했으나, 대용량 사진 전송 시 ESP32의 속도 한계와 잦은 멈춤을 경험했습니다. 이를 극복하기 위해 SD 카드를 다이렉트로 PC에 연결해 초고속으로 복사하는 방식을 메인으로 채택하되, 두 방식을 모두 지원하는 '투트랙 UI'로 발전시켰습니다.
- **초소형 보드(ESP32-C3) 호환성 확장**: SD 카드가 없는 내장 메모리(LittleFS) 기반의 소형 디스플레이(1.44인치) 보드를 위한 전용 시리얼 전송 클라이언트(Uploader)를 별도로 구축하고 UI를 현대적으로 개선했습니다.

---

## 3. 현재 도달한 최종 결과물 (Current Status)

위와 같은 숱한 실패와 구조 변경을 거쳐, 마침내 다음과 같은 안정적이고 사용하기 쉬운 생태계가 완성되었습니다.

1. **유연한 사진 수집 체계**: 로컬 웹앱을 통해 모바일 사진을 빠르게 수집 가능.
2. **원클릭 자동 최적화 앱**: 1~4번의 직관적인 번호 흐름을 따라 클릭만 하면, 크기 조절(320x240, 128x128 등)부터 EXIF 제거, 파일명 안정화까지 1초 만에 자동 처리되는 Windows/Mac용 독립 실행형 통합 매니저 앱(`.exe`, `.app`) 구축 완료.
3. **핫플러그(Hot-plug) 지원 펌웨어**: SD 카드를 도중에 뺐다 꽂아도 아두이노가 스스로 재부팅하여 화면을 띄워주는 안정적인 펌웨어 완성.

이 프로젝트는 단순한 코드 작성을 넘어, 하드웨어의 물리적 한계를 소프트웨어로 극복하고 사용자 경험(UX)을 극한으로 끌어올린 의미 있는 도전의 결과물입니다.
